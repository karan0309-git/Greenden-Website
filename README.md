# 🌿 Greenden – Plant E-Commerce Website

A responsive, modern e-commerce landing page and store layout for **Greenden**—a fictional online shop for houseplants, gardening tools, and greenery essentials. Built using **HTML5** and **Tailwind CSS**.

---

## 🚀 Features

*   **Responsive Design:** Fully responsive layout optimized for mobile and desktop screens using Tailwind's utility classes.
*   **Hero Section:** Highlighting promotional deals, featured indoor plants, and key call-to-action (CTA) buttons.
*   **Product Catalog & Filters:** Grid-based product showcases with hover animations, pricing, and category filters.
*   **Customer Reviews & Testimonials:** Reusable card components displaying ratings and buyer feedback.
*   **Newsletter Subscription:** Styled signup section for promotional discounts and updates.
*   **Utility-First Styling:** Clean, modern UI built without write-from-scratch custom CSS classes.

---

## 🛠️ Built With

*   **HTML5** – Semantic elements for layout structure.
*   **Tailwind CSS** – Utility-first CSS framework for fast, custom styling.
*   **FontAwesome / Heroicons** – For clean, modern UI icons (search, cart, rating stars, social links).
